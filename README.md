# Prompochat

Tens uma ideia mesmo incrivel e precisas de falar com o teu amigo mas não te queres dar ao trabalho de sair do terminal para abrir o browser?
Acontece a todos, estás prompo!

O prompochat ajuda-te a resolver todos estes problemas com um simples comando:
```bash
prompochat <Recipient address> <Port number>
```
